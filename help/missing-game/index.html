A game or edition is missing

Can't find a game? Before anything else, try searching a different way: the Western title, the Japanese title, romaji, or with a platform picked.

If it's still missing:

  • If the game is there but a region or edition isn't, add it from Improve this entry (see Adding a release or an edition)
  • If the game isn't on Tana at all, you can add it from the Add page
  • If you're not sure, leave a comment on the closest game page, or ask on our Discord
