How new games are added

Tana checks for new games every Monday morning (Japan time).

For Japan, it reads the release lists for Switch 2, Switch, PS5, and PS4, and adds every new physical release once its release date has passed. Games that were announced earlier wait until they're actually out, then get added the following Monday.

For the West, Switch games are added automatically when Nintendo's European catalogue shows a cartridge release. For PS5, PS4, and Switch 2, the catalogues don't say whether a game was sold on disc or only as a download, so an editor checks each new Western-only release before it goes in.

North American and European release dates for games already on Tana are refreshed at the same time.

Older platforms don't get new games anymore (with a few exceptions), so they're only updated through corrections and additions from collectors. If something is missing, see A game or edition is missing.
