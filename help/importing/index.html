Importing a collection

If you already keep your collection somewhere else, you don't have to add everything by hand. The importer reads Excel, CSV, TSV, plain text, and even PDF lists.

Tana works out what each column is from what's in it (titles, platforms, regions, condition, complete or loose, etc.), so the file doesn't need to follow a set format. Exports from other collection apps usually work fine.

Before importing, pick a default region for anything your file doesn't specify: Japanese, North American, European, Asian, or Korean. You can also pick a default platform, or let Tana work it out from the title.

You'll get a chance to review the matches before anything is saved. If something goes wrong anyway, you can undo the whole import in one go.
