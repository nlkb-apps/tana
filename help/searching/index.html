Help, Finding games

Searching

You can search for games in the “search” function in English, romaji (Japanese words in Latin characters), or in Japanese kana/kanji.

Next to the search box, you can use the platform menu to select which platform you’d like to drill down to into your search. For example, searching “Mario” will present all Mario games, whereas selecting Nintendo 64 and searching “Mario” will limit the search to all titles with Mario for the Nintendo 64.

Tana is set up for an international (English-speaking) audience, so for games which never left Japan a transliteration of the games title shows primarily. Tana uses a proprietary latinization function, so there is a chance you find games that only exist with Japanese characters— usually these are transliterated within a week. If not, feel free to leave a note or request for review.
