Help, Finding games

Reading a game page

Each platform is assigned a color (i.e. crimson for Switch 2, white for PS5, etc.) in the box spine, designed after a vertically set game on a shelf. You can see the Japanese title for each games as well when they exist.

Games are grouped by platform releases (i.e. the same "Assassin's Creed" game may have different pages for several platform versions) and have a single card for region.

There are different editions for each release in different kinds, labels, serials, barcodes, etc.

Each page shows how many collectors own the game and how many collectors want the game-- this comes from each user's data aggregated from over the site.

At the top of every page are the three things you'll do most: Add to collection, Want it, and Share. Add to collection lets you pick the exact edition you have (see Adding a game to your collection). Want it puts the game on your wantlist, and if it came out in more than one region it asks which release you're after. Once you own a copy, a line under the buttons tells you which edition is on your shelf.

Share button allows you to copy and paste the public page links for each game page.

On a computer, the box, title and buttons stay on the left while you scroll through the releases on the right.
