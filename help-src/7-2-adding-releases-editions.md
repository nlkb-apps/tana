# Adding a release or an edition

If a game is missing a release or an edition, you can add it yourself from Improve this entry on the game page.

Add a release when a region is missing completely (i.e. the game came out in Europe but Tana only has the Japanese release). You'll fill in the region, title, release date, and publisher.

Add an edition when the release is there but your version isn't. You'll pick:

- The release it belongs to and the kind (standard, reprint, limited, cover variant, etc.)
- A label, i.e. 初回版, PlayStation the Best, or Later-print cover
- What makes it different, in your own words
- The product code, JAN barcode, and what came in the box

For a different cover under the same product code, choose Cover variant and describe the change. New releases and editions show up on the game page right away.
