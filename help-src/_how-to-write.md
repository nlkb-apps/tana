# Writing the Tana help pages

One file per page. The block between --- lines at the top is page information (title, section, order);
leave it in place and change `status: draft` to `status: ready` when a page is done.

Each page has a hidden writer's checklist between <!-- and -->. It never appears on the site;
it lists what the page should cover. Delete it when you are finished with the page.

When Tana changes, new pages or headings are added here, and a dated heading is added to
"What's new" (B-whats-new.md), with its own checklist.

Pages marked `status: ready` are the ones that will be published under tana.gamingjapanese.com/help/.
Files starting with an underscore (like this one) are never published.
