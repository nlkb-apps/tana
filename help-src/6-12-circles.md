# Circles

A circle is a group of collectors chasing one set together: every Famicom Disk System game, every Japanese Saturn shooter, every Neo Geo cartridge. Every member's shelf counts toward the set, and the games nobody has yet become the circle's hunt list. Open them from Community, then Circles.

## Joining

Open a circle and choose Join this circle. Copies already on your shelf count straight away. You can be in up to twelve circles, and you can leave at any time.

Joining shows the circle which of its games you own. If your collection is private, you appear as "A member" in the members list and the feed.

## The circle page

- **Progress.** How many games in the set the members own between them.
- **The grid.** One square per game. Squares are filled for games the circle owns, gold for games found this week, and empty for games still being hunted. Squares on your own shelf have an outline. Hover over a square, or tap it, to see the game.
- **The hunt list.** The games nobody in the circle owns yet, with the ones members want first.
- **Lately.** Members' recent finds from the set.
- **Plates.** Brass plates the circle has earned (see below).

## Starting a circle

Choose Start a circle and give it a name, a few emblem letters and a colour. Then choose how the set is made:

- **A rule.** Up to six platforms, plus a region, Japan-only games, a range of years, a publisher, or words in the title. Tana shows how many games match as you go. A set can hold up to 2,000 games. When new releases match the rule, they join the set each week.
- **A hand-picked list.** Members add games one at a time from the circle page, and can remove them again.

You can start up to three circles.

## Goals and plates

The member who started a circle can set a goal for the month: a number of set games owned. If the circle reaches it by the end of the month, it earns that month's brass plate. Goals start fresh each month.
